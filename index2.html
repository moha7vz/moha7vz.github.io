🆘 Problèmes Courants

❌ Je ne reçois pas d'emails :

  1. Vérifiez que votre clé SpoofWave est valide
  2. Utilisez le bouton "Tester l'API" avec votre vraie adresse email
  3. Vérifiez vos spams/courriers indésirables
  4. Regardez les logs de debug ci-dessus pour voir les erreurs
  5. Vérifiez que SpoofWave fonctionne depuis leur site

⚠️ Messages d'erreur courants :

  • CORS error → Problème de navigateur
  • Network error → Problème de connexion
  • Rate limit → Trop d'envois
